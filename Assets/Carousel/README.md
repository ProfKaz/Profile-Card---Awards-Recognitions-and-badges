# Carousel assets

This folder contains the nine-slide English carousel created to introduce the project and the underlying business problem.

The carousel focuses on:

- Making verified capabilities visible inside Microsoft 365.
- Moving beyond outdated CVs and informal knowledge of who can do what.
- Publishing awards, certifications, badges and recognitions on Microsoft 365 profile cards.
- Using Microsoft 365 Copilot and people experiences to improve capability discovery.
- Explaining that the result requires a controlled ingestion and configuration process rather than being a completely plug-and-play feature.

These images are presentation/communication assets only. They are not required by the PowerShell implementation.
