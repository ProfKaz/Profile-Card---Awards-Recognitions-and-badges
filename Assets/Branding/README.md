# M365 Profile Card Awards branding

This folder contains the source-neutral visual identity used by the project.

## Meaning

- **Shield:** trust, protection and governance.
- **Profile card:** Microsoft 365 People Profile and organizational identity.
- **Gold award:** certifications, Microsoft Applied Skills, awards and professional recognitions.

## Asset families

| Folder | Purpose |
|---|---|
| `main/` | Production connector, repository and documentation assets |
| `beta/` | Test connector identity with a visible violet `BETA` marker |
| `flat/` | Simplified high-contrast assets for small UI surfaces |

## Recommended files

| Surface | File |
|---|---|
| GitHub repository | `main/m365-profile-card-awards-github-512.png` |
| Documentation and slides | `main/m365-profile-card-awards-docs-256.png` |
| Production Copilot connector | `main/m365-profile-card-awards-copilot-48.png` |
| Beta Copilot connector | `beta/m365-profile-card-awards-beta-copilot-48.png` |
| UI at 32 px or smaller | Matching asset from `flat/` |
| Windows multi-resolution icon | `flat/m365-profile-card-awards.ico` |

## Usage rules

- Use the production icon without the `BETA` marker for published connections.
- Reserve the Beta icon for isolated tests and preview environments.
- Keep the original aspect ratio and transparent padding.
- Do not add Microsoft, Microsoft Learn or Credly logos to the shield.
- Prefer the flat family at 32 px and below.
